
# Jenkins CI/CD Pipeline

## DevOps Internship - Task 2

This project demonstrates a simple CI/CD pipeline using **Jenkins and Docker** to automatically build, test, and deploy a web application.

## Objective

The objective of this task is to create a Jenkins Pipeline that automates the build, testing, and deployment process of an application.

## Technologies Used

- Jenkins
- Docker
- Docker-in-Docker
- Nginx
- GitHub
- HTML
- Jenkinsfile
